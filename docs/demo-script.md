## Setup (before demo)

```bash
pnpm dev           # boots web (3000) + api (8000)
# confirm: curl http://localhost:8000/health -> {"status":"ok"}
# confirm: http://localhost:3000 loads landing page
```

---

## Step 1: Show the problem (30s)

Open `examples/sample-nextjs-app/app/page.tsx` in editor — show the email input with no privacy policy.

> "This is a typical signup form. It collects email, name, phone — with zero compliance documentation."

---

## Step 2: Run the scan (60s)

```bash
npx shipcomply scan ./examples/sample-nextjs-app
```

Watch Ink UI show:
- Files scanned
- PII elements detected: email, name, phone
- Scan ID

Navigate to `http://localhost:3000/scans/<scan_id>` — show compliance score ring.

---

## Step 3: Show generated artifacts (60s)

In `.shipcomply/` (generated by scan):
- `PRIVACY.md` — privacy policy with file:line citations
- `compliance-score.json` — score with scope denominator
- `generated/ConsentBanner.tsx` — ready-to-drop React component

Open `PRIVACY.md` — show the citation: "`app/page.tsx:6` — email input → DPDP Section 4 requires consent"

---

## Step 4: Show GitHub App (30s)

Switch to fork with ShipComply app installed — open a PR with a new email input — show bot comment appear within ~60s.

---

## Contingency — offline

If no wifi:
```bash
pnpm demo:offline
npx shipcomply scan ./examples/sample-nextjs-app --offline
```
Full pipeline runs via local Ollama + Postgres.
